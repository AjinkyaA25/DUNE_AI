# Leader card text (verified 2026-10-16)

Transcribed from the card images on dunecardshub.com (`data/leader_cards/*.webp`)
plus the rulings listed on each card's page. Icon key, taken from the starter
Signet Ring card: green pentagon = Landsraad, blue/purple circle = City,
yellow triangle = Spice Trade (`desert` in the engine); helmet = Emperor,
red infinity = Spacing Guild, purple mask = Bene Gesserit, blue = Fremen.
Hexagon = spice, round coin = solari, blue diamond = persuasion, cube = troop,
cylinder = spy, cylinder with up arrow = recall a spy, card with X = trash a
card, gold card = Intrigue card, green card = draw a card, drop = water.
**(?)** marks a reading that is still an interpretation.
